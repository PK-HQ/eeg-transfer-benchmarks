# Frozen Damm2026 benchmark design

Use OpenNeuro ds008446 v1.0.1. Pilot on the first random run of subjects 01–04. If EDF, labels, and timing pass, run both runs of both conditions for all 20 subjects. The pilot participants remain in the cohort. Fit random and sequential models separately using leave-one-participant-out folds. Report random order as primary, with sequential order as a diagnostic.

Before cohort fitting, check the released stimulus assets and independently match corrected TSV codes to the EDF Marker channel where available. The source assets show a white screen, a fixation cross, and five hand drawings each highlighting a different digit in blue. The marker records three seconds each for white screen and fixation, followed by a nominal six-second labeled imagery phase. The deposit does not separately log image offset or measured screen presentation, so late-window features can still carry visual or attentional information. The stimulus audit and ERD time course were added after the initial four-run smoke test and before cohort scoring, without changing the classifier.

Use trial-local Hann periodograms and log power in 8–12 and 12–30 Hz. The motor and posterior sets contain 15 scalp channels each. Primary features use the late imagery window [3.5, 5.5) seconds. Compare the same windows and penalty for motor and posterior features, all 62 scalp channels as a separate comparator, motor and posterior features at [0.5, 2.5), and all-scalp pre-cue power at [−2, 0). Use all-scalp early cue amplitudes in four 100 ms bins from 80 to 480 ms, referenced to the previous 250 ms. Windows are independently sliced without continuous filtering. Estimate sensor-group ERD as mean trial-level dB power change from fixation [−3, −1) in each band and window, aggregating over trials then subjects.

For the trial-level time course, calculate absolute log power and baseline-relative dB change in nine disjoint one-second bins from −3 to +6 seconds. Use the same pre-cue fixation baseline, averaging log power over each scalp set. These descriptive changes track cue-relative physiology and can reflect visual attention or anticipation.

Use weighted standardization and fixed multinomial L2 logistic regression (C=0.1), balancing subjects, runs and classes within runs. No tuning or artifact exclusions based on decoding outcomes. Report separate non-EEG baselines using run number and absolute trial position, and previous true cue with a first-trial sentinel, learned only in training subjects. The latter is an oracle diagnostic. Whole participants, including all temporally adjacent trials and all runs, stay in one outer fold. Report run-specific results alongside pooled participant scores.

Report participant-mean balanced accuracy, pooled confusion counts, and descriptive paired 95% bootstrap intervals over participants (10,000 draws, seed 2026), conditional on these overlapping training folds. Compare with nominal 20% balanced chance. Reliable late motor decoding with reproducible advantages over matched posterior and early cue controls plus a motor-centered ERD pattern would favor a motor-related interpretation, with residual cue confounding. Predictability without that pattern favors the cue-ambiguous conclusion. Intervals compatible with chance for the primary and cue EEG readouts provide no reliable decoding evidence. Control contrasts are descriptive.
